How Data is Fetched and Handled Online vs. Locally

          
Dual-engine resilient architecture for continuous counter operation and cloud global storefront.

        

      


      

        

          

             1. Online / Vercel Serverless Architecture
          

          

            When deployed to Vercel (rani-hyper-market.vercel.app), the application runs on stateless serverless edge functions:
          

          
    
            
  • Router: All API requests pass through /api/index.js via Vercel rewrites.
    • 
            
  • Zero-Crash Failover: If native Windows binaries (sqlite3.exe, tasklist) are absent in the Linux container, analyticsService.js automatically falls back to in-memory JSON data snapshots.
    • 
            
  • Pre-baked Authentic Snapshots: products_catalog.json (7,179 products), rani_orders.json, rani_customers.json, and rani_analytics.json provide 100% instant responses without waiting for database spin-up.
    • 
            
  • Supabase Non-Blocking Guard: All queries to remote Supabase have an instant local fallback. If DNS or network is unreachable, orders, logins, and cart operations proceed with zero timeout or spinner freeze.
    • 
          

        


        

          

             2. Local Desktop POS & Hardware Bridge
          

          

            On the physical retail store computer at Bodinayakanur (localhost:5500):
          

          
    
            
  • Live SQLite Engine: Directly queries the active multi-year retail databases in C:\SKS Market\*.db (e.g. FY 2026-2027).
    • 
            
  • Barcode Scanner & POS Modal: Supports instant barcode reader lookups (GTIN-8, GTIN-13) and live product bill parking.
    • 
            
  • Thermal Receipt Printing: Drives 80mm ESC/POS receipt printers directly via browser print spooler or serial COM port bridge.
    • 
            
  • MarkBot Daemon: Continuously monitors catalog health, stock thresholds, and syncs newly recorded counter bills into web snapshots automatically.
    • 
          

        

      

    


    
    

      

        

          
        

        

          
Deep Dive: Every Tool & Service of Rani & NSN Market

          
Comprehensive educational syllabus covering functionality, data inputs, and outputs.

        

      


      

        
        

          

            01
            Customer Storefront (store.html)
          

          

            Mobile-optimized customer shopping portal with 7,179 authentic Indian FMCG items across 10 staple categories (Rice, Dhall, Cooking Oils, Spices, Dairy, Soaps).
          

          

            Key Features: Instant fuzzy search, category filter pills, sticky cart drawer, OTP-free WhatsApp order dispatch, and delivery fee calculation.
          

        


        
        

          

            02
            Rani Brand Showcase (rani.html)
          

          

            Dedicated brand landing page celebrating Rani Hyper Market's location at Anwar Complex, Bodinayakanur with live location map and store history.
          

          

            Key Features: Store GPS navigation link, WhatsApp direct ordering, wholesale bulk inquiry modal, and verified packaging packshots.
          

        


        
        

          

            03
            Counter POS Register (admin.html Modal)
          

          

            High-speed supermarket billing terminal designed for counter staff. Handles barcode scanner input, cash and UPI reconciliation, and park/resume queues.
          

          

            Key Features: Sub-second barcode lookups, camera packshot capture, instant bill park queue, and WhatsApp electronic receipts.
          

        


        
        

          

            04
            Bill & Audit History (bill_history.html)
          

          

            Complete transaction ledger for all past sales. Allows searching by bill number, customer phone, date range, or payment type.
          

          

            Key Features: Instant thermal re-print, GST tax breakdown, Excel/CSV export, and customer purchase aggregation.
          

        


        
        

          

            05
            AI Festival Stock Forecaster
          

          

            Predictive machine-learning model calculating festive demand surges across Bodinayakanur (Pongal, Diwali, Ramzan, Tamil New Year).
          

          

            Key Features: Item-specific reorder surge multipliers (e.g. Rice 3.2x, Ghee 4.1x), procurement lead-time warnings, and revenue projections.
          

        


        
        

          

            06
            MarkBot Autonomous Supervisor
          

          

            Self-governing background intelligence agent (markbot_daemon.js) monitoring system performance and auto-improving code.
          

          

            Key Features: Runs continuously, verifies zero-broken packshots, ensures 100% cloud endpoint parity, and logs audit health logs.
